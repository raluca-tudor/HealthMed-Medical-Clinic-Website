# HealthMed Medical Clinic Website
A multi-page HTML website for a modern medical clinic (HealthMed) that presents services, medical staff, a photo gallery and contact information.

# Project Overview
This project is a multi-page static website developed for **HealthMed Medical Clinic**. The goal of this project is to provide a clean, professional, and user-friendly digital presence for the clinic, allowing patients to easily access information about the clinic's services, meet the medical staff, view modern facilities and find contact details.
The website is built using standard HTML (HTML 4.01 Strict) with a focus on clear information architecture, semantic structure and a calming, professional visual aesthetic suitable for the healthcare domain.


# Objectives
- Create a cohesive multi-page website for a fictional medical clinic.
- Present medical services, pricing, and specialty descriptions in a clear format.
- Introduce the clinic's team of doctors with their credentials and specialties.
- Showcase the clinic's modern equipment and interior design through a photo gallery.
- Provide essential contact information, operational hours, and physical address.
- Ensure intuitive navigation across all pages for potential patients.


# Technologies
- HTML 4.01 Strict
- CSS (Inline & Internal '<style>' blocks)
- Static Web Assets (Images)

# Features
- **Intuitive Navigation Menu:** Easy access to all major sections from the main page ('index.html').
- **Information Architecture:**
  - **Home:** Welcome message and clinic philosophy, including special offers.
  - **Medical Services:** Detailed list of medical specialties, current price list and an educational table explaining what each specialty treats.
  - **Medical Staff:** A complete directory of the clinic's doctors, sorted by specialty, including their titles and contract status with the National Health Insurance House (CNAS).
  - **Photo Gallery:** Visual presentation of the clinic's modern interior, high-tech equipment (Ultrasound, ECG, EEG, Mammography) and medical staff.
  - **Contact Page:** Phone numbers, email address, operational schedule and location.
- **Professional Design Elements:** 
  - Consistent header and footer layout across all pages.
  - Informational iconography (phone, email, location pins).
  - Unique background images tailored to each page's theme.
- **Promotional Campaign Display:** Highlights a limited-time medical package for patients with referral letters (July - September 2025).

# How to Run
This is a static HTML website, so no server-side setup is required.
1. Download or clone the repository.
   'bash
   git clone https://github.com/your-username/HealthMed-Medical-Clinic-Website.git'
2. Navigate to the project folder on your computer.
3. Simply double-click on index.html to open the website in your default web browser.
